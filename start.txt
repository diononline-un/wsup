One-Shot Coding Agent PromptDu kannst den folgenden Block direkt in deinen AI-Coding-Agenten (Claude Code, OpenCode, Cursor etc.) kopieren:MarkdownYou are an expert full-stack developer building a SaaS application called "Supplement Stack Calculator" using SvelteKit, Tailwind CSS, PocketBase, and Node.js with OpenRouter.

### Core Objective
Build a multi-tenant Cloud SaaS platform that generates evidence-based supplement and peptide stacks based on user biometrics, lifestyle, medications, and cycle data, including an anonymous auth flow, a "Bring Your Own Stack" (BYOS) matching engine, and dynamic ICS calendar subscription feeds.

### Technical Stack & Requirements
1. Frontend: SvelteKit with Tailwind CSS (English-first, clean UI, metric/imperial toggle).
2. Backend/Database: PocketBase.
3. AI Service: Node.js service connecting to OpenRouter API (DeepSeek / Claude) for analyzing paper research and computing confidence scores.
4. Deployment Target: Multi-tenant Cloud SaaS (Basic Tier: 1 ICS feed free; Pro Tier: 3 ICS feeds, Safety Override Mode, advanced AI queries).

### Key Features to Implement
1. Anonymous Authentication:
   - Username + Password auth in PocketBase (NO email field).
   - Generate a 25-word recovery seed phrase on signup.
   - Force download of a `.txt` file containing the seed.
   - Require verification of 3-5 random words from the seed before completing onboard registration.

2. Comprehensive User Profiling (Inclusive UX):
   - Capture Age, Height, Weight, Biological Sex, Gender Identity.
   - Sleep quality, Activity level, Caffeine intake, Location/Country (for UV/D3 calculation), Allergies, Medications (e.g., ADHS meds/Bupropion).
   - Female Cycle Tracking: Cycle regularity, PMS/cycle symptoms.
   - Add info tooltips (I) for every field explaining "Why we ask this".

3. Recommendation Engine & Confidence Score:
   - Calculate a 0-100% Confidence Score based on profile completeness.
   - Color-coded indicators (Green = high data, Yellow = assumption made, Red = risk/conflict).
   - Support standard baseline portfolio (Multivitamin, Creatine) + specialized Peptides.
   - Display explicit Medical Disclaimer modal on first launch requiring user acknowledgment.

4. Bring Your Own Stack (BYOS) & Safety Override:
   - Allow users to enter custom supplements, dosages, and times.
   - Compute a "Matching Score" (%) against ideal recommendations.
   - Detect redundancies and over-dosages.
   - Implement a "Safety Override Mode" toggle for Pro Users to dismiss high-dose warnings (with confirmation logging).

5. ICS Calendar Feed Generator:
   - Generate secure, tokenized `.ics` webcal endpoints (`/api/v1/calendar/:token.ics`).
   - Allow up to 1 feed for Basic tier, up to 3 feeds for Pro tier.
   - Parse dosage times into iCal events.

6. Database Schema (PocketBase Collections):
   - Create collections for: `users`, `user_profiles`, `substances`, `substance_interactions`, `user_stacks`, and `calendar_feeds`.

Please start by setting up the PocketBase collection definitions, the SvelteKit project structure, and the anonymous signup flow with 25-word seed verification.
